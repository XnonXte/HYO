# HYO - Hear Your Own 💙

A responsive mental health and wellness companion web application built with React, TypeScript, Vite, and Tailwind CSS based on the official Figma design.

## Features

- **Dashboard / Home**: Daily mood check-in with 5 distinct mood states, "Talk to Hyo" hero card, and personalized activity plans.
- **AI Talk Companion (Aisa/Hyo)**: Interactive voice and speech simulation with visual animated sound waves, thinking states, and supportive responses.
- **Journaling & Reflection**: Live searchable and filterable journal entries with squircle date stamps and session badges.
- **Detail Journal View**: Full reflection view with mood summary, counselor support hotlines, and 4-day structured recovery roadmap.
- **User Profile**: Personal stats (entries, talk sessions, mood improvement), bio, and scheduled activities.
- **Interactive Modals**: Counselor connect modal, application preferences & settings modal, and activity detail tracker.
- **Mobile First Design**: Anchored navigation pill bar, full viewport height (`100dvh`), and authentic Figma assets.

## Tech Stack

- **React 19**
- **TypeScript**
- **Vite 8**
- **Tailwind CSS**
- **Lucide React**
